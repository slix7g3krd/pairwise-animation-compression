# pairwise-animation-compression

动画压缩后角色手臂在快速挥砍时穿进身体，四元数按每个分量独立量化，插值后长度不为 1；关键帧按固定误差剪枝，旋转误差在 180 度附近被低估，翻转动作直接丢失；根运动被压进骨骼轨道，位移缩放后脚步滑行；加法层与基础层在不同帧率下混合，叠加层的关键帧被重采样两次；缩放通道用 16bit 定点，超过 10 倍的角色变形成负值；循环动画的首尾帧没对齐，压缩后接缝处出现一顿；动画事件挂在被剪掉的关键帧上，攻击判定不触发；压缩器按骨骼独立选择精度，左右手的误差不一致，握持物体偏移；不同平台用不同 SIMD 路径解码，浮点结果差一位，回放不同步；压缩比按字节数静态分配，长动画的后半段精度越来越低。render/animation_compression.py 是核心，tests/test_animation_compression.py 15个红。要修的是：四元数归一化插值；按旋转弧长剪枝；根运动单独轨道；统一采样率；缩放用浮点；首尾对齐；事件保留；双手共享精度；解码走定点一致路径；按时间分段分配。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
